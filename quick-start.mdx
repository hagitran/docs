## Get Started in 2 Steps

<Steps>
  <Step title="1. Get Your API Key">
    Sign up at [whetdata.com](https://whetdata.com/dashboard) and grab your API key from the dashboard.
  </Step>
  
  <Step title="2. Try All Features">
    Test the endpoints to see the full power of the API:
    
    **Get improvement suggestions:**
    ```bash cURL
    curl -X POST https://whetdata.com/api/ult \
      -H "x-api-key: your-api-key-here" \
      -H "Content-Type: application/json" \
      -d '{
        "action": "nudges",
        "ruleset": "product_description",
        "text": "This product is good and works well.",
        "max_nudges": 3
      }'
    ```
    
    **Clean spelling and grammar:**
    ```bash cURL
    curl -X POST https://whetdata.com/api/ult \
      -H "x-api-key: your-api-key-here" \
      -H "Content-Type: application/json" \
      -d '{
        "action": "clean",
        "ruleset": "product_description",
        "text": "This is a sentance with speling and grammer erors that need to be fixed."
      }'
    ```
  </Step>
</Steps>

## API Actions

Our API supports three main actions through a single endpoint:

- **Classification**: Analyze text into 10 semantic categories (factual, analytical, emotive, etc.)
- **Nudges**: Get actionable improvement suggestions with priority scoring
- **Clean**: Fix spelling and grammar errors automatically
