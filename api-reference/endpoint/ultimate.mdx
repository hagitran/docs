## Overview

The Ultimate endpoint is a central orchestrator that executes multiple text processing operations in parallel. You can batch classification, nudges, and clean operations together to get combined results in a single request.

## Use This Endpoint To

- Batch multiple operations together for efficiency
- Get combined results from classification, nudges, and clean in one request
- Reduce API calls by combining operations

<Tip>
  This endpoint executes all requested operations in parallel, so batch requests
  are faster than making separate API calls.
</Tip>

## Parameters

<ParamField body="action" type="array" required>
  Array of operations to execute: `["classification"]`, `["nudges"]`,
  `["clean"]`, or any combination like `["classification", "nudges"]`
</ParamField>

<ParamField body="text" type="string" required>
  Text to process (max 5,000 characters)
</ParamField>

<ParamField body="ruleset" type="string">
  Ruleset name (required for nudges and clean operations)
</ParamField>

<ParamField body="max_nudges" type="integer">
  Maximum number of nudges to generate (required for nudges action)
</ParamField>

## Example

```bash cURL
curl -X POST https://whetdata.com/api/ult \
  -H "x-api-key: whet_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "action": ["classification", "nudges"],
    "text": "Premium wireless headphones with active noise cancellation.",
    "ruleset": "product_review",
    "max_nudges": 3
  }'
```

## Tips

<Warning>
  The maximum text length is 5,000 characters. For longer texts, split them into
  chunks.
</Warning>

<Info>
  For individual operations, use the dedicated endpoints:
  [Classification](/api-reference/endpoint/classification),
