## Overview

Generate actionable improvement suggestions for your text. This analyzes your content and provides specific, prioritized recommendations to enhance quality and conversion potential. The endpoint is `POST /api/ult`; the request body sets `action` as an array that includes `"nudges"`.

## Parameters

<ParamField body="action" type="array" required>
  Must be an array that includes `"nudges"`.
</ParamField>

<ParamField body="ruleset" type="string" required>
  Ruleset to use (for example `product_description`).
</ParamField>

<ParamField body="text" type="string" required>
  Input text (max 5,000 characters).
</ParamField>

<ParamField body="max_nudges" type="number" default="3">
  Number of suggestions to return (minimum 1).
</ParamField>

## Example

```bash cURL
curl -X POST https://whetdata.com/api/ult \
  -H "x-api-key: whet_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "action": ["nudges"],
    "ruleset": "product_description",
    "text": "This product is good and works well.",
    "max_nudges": 3
  }'
```

## Use This Action To

- Improve existing product descriptions
- Generate variations for A/B testing
- Identify gaps in your content strategy
- Learn what makes effective copy

## Tips

<Tip>
  Start by requesting 3-5 nudges initially. Focus on high-priority suggestions
  first for maximum impact.
</Tip>

<Warning>
  The maximum text length is 5,000 characters. For longer texts, split them into
  chunks.
</Warning>
