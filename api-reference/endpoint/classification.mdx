## Overview

Classify text into semantic categories. It analyzes your text and provides scores across categories. Each category receives a score from 0 - 100.

## Categories
- To use this endpoint, you either need to provide a list of categories (through the endpoint), or use a premade list (which are designed for each industry).

## Use This Action To

- Understand the semantic characteristics of your text
- Analyze content style and tone
- Classify documents by their primary purpose
- Measure how descriptive, persuasive, or factual your content is

## Parameters

<ParamField body="action" type="array" required>
  Must be an array that includes `"classification"`
</ParamField>

<ParamField body="text" type="string" required>
  Text to classify (max 5,000 characters)
</ParamField>


## Example

```bash cURL
curl -X POST https://whetdata.com/api/classification \
  -H "x-api-key: whet_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "categories" = ["sentiment_overall","is_positive","is_negative","is_neutral","mentions_taste","mentions_temperature","mentions_portion_size","mentions_freshness_or_quality","mentions_missing_items","is_actionable","requests_refund","reports_problem","reports_health_or_safety_issue","mentions_app_or_payment_issue"]
    "text": "The food actually tasted really good, but it arrived completely cold and one of the dishes was missing. I’d like a refund because this was really disappointing."
  }'
```
