## Authentication

All API endpoints are authenticated using API keys passed in the `x-api-key` header.

```bash
curl -X POST https://whetdata.com/api/ult \
  -H "x-api-key: whet_your_api_key_here" \
  -H "Content-Type: application/json"
```
