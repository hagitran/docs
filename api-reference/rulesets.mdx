Rulesets define the criteria used for text classification and nudge generation. Each ruleset is tailored for specific content types and industries.

## Available Rulesets

| Ruleset                   | Description                                   | Best For                        |
| ------------------------- | --------------------------------------------- | ------------------------------- |
| `product`                 | E-commerce product copy rating and editing    | Product listings, descriptions  |
| `product_description`     | Product description analysis and optimization | Online retail, marketplaces     |
| `marketing_copy`          | Marketing copy effectiveness analysis         | Ad campaigns, landing pages     |
| `product_review`          | Product review authenticity and helpfulness   | Customer reviews, testimonials  |
| `technical_documentation` | Technical documentation clarity analysis      | API docs, user manuals          |
| `date_online`             | Dating app prompt response optimization       | Dating profiles, social content |
